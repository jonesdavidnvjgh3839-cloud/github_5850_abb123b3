# Product Catalog

The Nimbus Cloud knowledge base documents these products:
- **Nimbus Compute** (`nimbus-compute`) — Nimbus Compute provides scalable, on-demand virtual machines and container orchestration for running production workloads with predictable performance and granular control.
- **Nimbus Storage** (`nimbus-storage`) — Nimbus Storage offers durable, high-availability object and block storage with tiered pricing, encryption at rest, and global replication for mission-critical data.
- **Nimbus Network** (`nimbus-network`) — Nimbus Network delivers software-defined networking, managed load balancing, and private connectivity so you can build secure, low-latency architectures across regions.
- **Nimbus Database** (`nimbus-database`) — Nimbus Database is a fully managed relational and NoSQL database service with automated backups, point-in-time recovery, and horizontal scaling.
- **Nimbus Security** (`nimbus-security`) — Nimbus Security centralizes identity, access, encryption, and threat monitoring to help you meet compliance and protect your cloud environment.
